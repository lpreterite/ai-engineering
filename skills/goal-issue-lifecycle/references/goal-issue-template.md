# Goal Issue 正文标准结构

> 引用：`skills/goal-issue-lifecycle/SKILL.md` 步骤 1

## 正文结构

```
## 目标
<一句话描述这个需求的目标>

## 验收标准
- [ ] ① 业务时序：角色与行为已明确
- [ ] ② 解决方案：改造方案已确认

## 阻塞项（= 子任务清单）
- [ ] _(由 Agent 在打磨期逐步增补，执行期勾选清零)_

## 关联
- 设计文档：<相关文档路径>
```

## 与 0-goal.yml 的对应关系

| 0-goal.yml 字段 | 正文章节 |
