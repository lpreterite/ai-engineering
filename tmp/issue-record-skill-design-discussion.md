# 清晰度定义

## 概念

清晰度指软件制作过程中其组成内容的细节及完整性。

## 类比：登山

听人讲解登山过程和实际登山的感受和见解，清晰度是不同的。

| 状态 | 实例 |
|------|------|
| 模糊想法 | 听人讲登山 |
| 需求雏形 | 看路线图 |
| 明确需求 | 站在山脚 |
| 设计方案 | 爬到半山腰 |
| 技术方案 | 登顶前最后一段 |
| 可执行任务 | 登顶后的全景感受 |

## 内容成熟度阶段

| 阶段 | 典型特征 | 内容完整性 |
|------|----------|-----------|
| 模糊想法 | "我想做个XXX" / 用户金句多 | 问题方向有，细节无 |
| 需求雏形 | "主要解决...场景是..." | 有场景有痛点，无边界 |
| 明确需求 | "支持A/B/C功能，D不做" | 有范围有边界 |
| 设计方案 | "用方案X，交互流程是..." | 有具体方案 |
| 技术方案 | "数据库选型、接口设计、部署" | 有技术细节 |
| 可执行任务 | 可拆解为 Story/Task | 有验收标准 |

## 判断信号

AI 从 `analysis` 和 `decision` 中提取特征：

- 有没有明确的**边界**（要什么/不要什么）→ 需求 vs 想法
- 有没有**方案比较** → 设计阶段
- 有没有**技术选型依据** → 技术方案阶段
- 有没有**可验收的标准** → 可执行阶段
